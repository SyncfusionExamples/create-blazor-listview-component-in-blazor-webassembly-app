# Blazor ListView - Getting Started

This repository contains a Blazor WebAssembly sample that shows how to configure the [Blazor ListView](https://www.syncfusion.com/blazor-components/blazor-listview) component in a compact, real-world app.

The sample focuses on a nested list scenario and demonstrates how to wire up services, load the Fluent 2 theme, and render a hierarchical ListView with strongly typed data.

## Overview

This sample provides a practical starting point for building list-driven user interfaces with Blazor. It shows the minimum app setup required to display a nested ListView, while keeping the code easy to read and extend.

Use this project to understand how the ListView is registered, styled, and bound to hierarchical data in a Blazor WebAssembly app.

## Features

- Blazor WebAssembly app with ListView integration
- Nested, hierarchical item rendering
- Headered ListView layout
- Strongly typed sample data model
- Fluent 2 theme loaded from assets
- Minimal structure for quick experimentation

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/https://github.com/SyncfusionExamples/create-blazor-listview-component-in-blazor-webassembly-app.git.git
cd create-blazor-listview-component-in-blazor-webassembly-app.git
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
